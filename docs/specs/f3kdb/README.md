# F3kdb 算法与行为规格

**新实现首先阅读 [新实现契约](new-design.md)。** 它已确定数值域、预设、随机过程、输出与验收规则，优先于本目录历史行为文档。其余文档用于算法展开，不再要求实现者在历史行为之间自行选择。

新实现支持平面 Gray/YUV、整数 8…16 位及 F16/F32，保留七模式和单滤镜三阶段设计。RGB/alpha 不在本轮范围。性能优先，但近似必须满足明确的误差门槛；不要求复现旧结果。

## 语义层次

- **数学定义**：以实数、整数和有限序列定义运算，不包含机器指令近似。
- **整数兼容定义**：显式保留会影响像素值或随机序列的离散规则，例如逐对平均、随机数消耗次序和误差分配中的截断。
- **数值变体**：公开算法存在可观察差异的计算形式，例如精确的十分之一次幂与快速近似。选择变体后必须固定下来，不能在不同目标上无声明地混用。
- **待决语义**：现有公开行为不足以给出跨平台唯一结果的地方，不假定其已经确定；集中列在验收文档。

所有坐标以左上角为原点，横向为 `x`，纵向为 `y`。宽、高、帧数分别为 `W,H,N`。输入位深为 `b`，输出位深为 `d`，内部整数标度固定为 16 位。`clip(v,a,b)=min(max(v,a),b)`；`floor` 为向负无穷取整；`trunc` 为向零取整。`⊕` 表示按位异或。

规格描述三个内部阶段：Deband → Grain → Dither/Output。它们组成一次滤镜处理，不要求暴露三个独立滤镜，也不要求分配三张中间图像。

模式 7 和距离规则已确定；其余数值选择已由 new-design.md 收束。幂函数具体近似、缓存布局与调度由实现者在质量门槛内测量选择，不再需要用户逐项拍板。本文可用于设计，不作为“与所有既有行为逐像素一致”的承诺。
