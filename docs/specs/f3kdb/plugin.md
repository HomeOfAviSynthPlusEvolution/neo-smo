# 参数与处理流程

> 本文保留整数算法的参数背景；新实现的格式、参数类型、预设、输出选择及旁路规则以 [新实现契约 N01…N03、N07](new-design.md) 为准。不得将下文历史行为覆盖到新规则。

## F3K-P01 输入输出契约

输入为有限帧数的平面 YUV 整数视频：`8≤b≤16`，`W≥16`，`H≥16`，`N>0`。色度横、纵子采样指数分别为 `s_x,s_y`，范围为 0 至 4；宿主必须提供与这些指数一致的平面尺寸。Y 平面大小为 `W×H`，Cb/Cr 为 `(W/2^s_x)×(H/2^s_y)`；尺寸除法应精确，非法格式应在处理前拒绝。

输出保留宽、高、帧数、帧率和子采样，改变位深至 `d`。输出为独立平面整数样本；8 位每样本一个字节，9 至 16 位每样本一个 16 位容器。容器字节顺序属于宿主绑定。不得将“16 位内部处理”解释成输入满量程归一化。

## F3K-P02 参数表

| 参数 | 默认值 | 范围或含义 |
|---|---:|---|
| `range` | 15 | 整数 0…255，参考点最大距离；完整支持 128…255，不作有符号 8 位折回 |
| `y, cb, cr` | 各 64 | 各平面的主阈值；`scale=false` 为 0…511，`true` 为 0…65535 |
| `y_1, cb_1, cr_1` | 继承对应主阈值 | 模式 5…7 的最大单点差阈值；范围同主阈值 |
| `y_2, cb_2, cr_2` | 继承对应主阈值 | 模式 5…7 的成对差阈值；范围同主阈值 |
| `grainy, grainc` | 各 64 | 整数 0…4096；分别控制 Y 与 Cb/Cr |
| `sample_mode` | 2 | 整数 1…7 |
| `seed` | 0 | 32 位随机种子输入 |
| `blur_first` | true | 仅模式 1…4 使用 |
| `dynamic_grain` | false | 是否按帧改变颗粒窗口 |
| `dither_algo` | 3 | 1=截断，2=有序抖动，3=误差扩散 |
| `keep_tv_range` | false | 是否按平面限制 TV 范围 |
| `output_depth` | -1 | -1=输入位深；否则 8…16 |
| `random_algo_ref` | 1 | 参考点随机算法：0=legacy，1=uniform，2=Gaussian |
| `random_algo_grain` | 1 | 颗粒随机算法，枚举同上 |
| `random_param_ref` | 1.0 | Gaussian 标准差参数 |
| `random_param_grain` | 1.0 | Gaussian 标准差参数 |
| `preset` | 空 | 按 `/` 分隔的预设序列 |
| `scale` | false | 主阈值及两组辅助阈值的数值单位 |
| `angle_boost` | 1.5 | 模式 7 的有限非负阈值倍率；乘积须在计算类型中有限 |
| `max_angle` | 0.15 | 有限值 0…1；单位为 π 弧度，实际无向夹角容差在 0.5 处饱和；默认 27° |
| `opt` | -1 | 执行后端选择，不是数学算法参数 |
| `mt` | true | 是否允许平面并行，不改变算法结果 |

继承阈值在参数层可用 `-1` 表示，但算子接收的最终阈值必须非负。除明确的默认值标记及 P03 所列输出深度的历史规则外，不将其他负数自动解释为默认值。`max_angle`、`angle_boost` 的非有限值必须拒绝；其他浮点参数的异常值策略见验收文档。

`opt` 的公开取值为 -1 自动、0 通用、1 SSE4.1、2 AVX2、3 AVX-512。后端不可用时的选择策略属于宿主绑定；它不允许更改数学模式。不同数值变体的像素差异不能用“优化选项”掩盖。

## F3K-P03 参数解析顺序

先读取 `scale`，因为它决定强度预设使用的数值；再按初始默认值 → 从左到右应用预设 → 显式参数覆盖 → 辅助阈值继承的顺序确定参数。随后解析输出深度及 16 位直通路径，检查有效域，并进行强度单位转换。不能先按 `scale=false` 展开预设，再补读 `scale`。

`output_depth=-1` 是规范的默认标记；历史参数处理也把其他负值解释为输入位深。新接口若只接受 -1，属于收紧参数契约，不能宣称完全保留此项历史行为。

主、辅助阈值原始值记为 `t`，内部阈值为：

\[
T=\begin{cases}4t,&scale=false\\t,&scale=true.\end{cases}
\]

颗粒原始强度 `g` 的内部范围始终为 `G=4g`，与 `scale` 无关。此处 `scale` 不是视频输入位深，也不是输出位深。默认主阈值和颗粒强度均对应内部数值 256。

`d=16` 时输出不需要位深量化抖动，选择直接 16 位输出。内部枚举值 4 表示此路径；它不是第四种面向用户的抖动算法。非法输出深度不应传入移位、查表或量化运算。

## F3K-P04 预设

令“全部强度”包含三个主阈值、六个辅助阈值及 `grainy/grainc`。

| 预设 | 作用于原始参数值 |
|---|---|
| `depth` | 全部强度置 0 |
| `low` | 全部强度置 32；`scale=true` 时置 128 |
| `medium` | 全部强度置 48；`scale=true` 时置 192 |
| `high` | 全部强度置 64；`scale=true` 时置 256 |
| `veryhigh` | 全部强度置 80；`scale=true` 时置 320 |
| `nograin` | 两个颗粒强度置 0 |
| `luma` | `cb,cr,grainc` 置 0 |
| `chroma` | `y,grainy` 置 0 |

空 token 忽略，未知 token 应报错。预设次序有意义，例如 `medium/nograin` 与 `nograin/medium` 不同。`luma/chroma` 只改列出的字段：之前已由预设赋值的辅助阈值不会自动清零；仍为继承标记的辅助阈值才跟随主阈值解析。这样可能影响旁路条件，不能把预设名字当作平面屏蔽开关。

由于颗粒总是乘 4，`scale=true` 的强度预设会令颗粒比同名 `scale=false` 预设更强；这是参数组合的兼容行为，不应默默修正。

## F3K-P05 生命周期与流水线

创建时：解析参数，确定平面格式，建立参考点表及颗粒序列，必要时建立每帧颗粒窗口偏移。它们由尺寸、帧数、种子和参数决定，不取决于之后请求帧的次序。

处理帧 `n` 时，各平面独立执行：

1. 判断完整旁路条件。
2. 读取原始平面并转换到内部整数标度。
3. 使用预生成参考点和原始输入做 Deband。邻居读取不得读取已经处理过的输出。
4. 加上该平面、该帧的颗粒。
5. 进行输出抖动、范围限制及位深量化。

只请求当前输入帧，没有时间域图像参考。动态颗粒改变的是颗粒窗口，不改变 Deband 的参考点表。每次处理平面都从空误差状态开始；误差扩散不能跨帧或跨平面传播。

完整旁路条件：`b=d`、该平面颗粒强度为 0，且该平面三个阈值全部为 0。满足时逐样本复制输入，不执行 TV 范围限制或抖动；因此即使 `keep_tv_range=true`，旁路仍会保留超 TV 范围值。不能仅检查模式实际使用的一个阈值来替换此兼容条件。

帧间、平面间可以并行；输出必须与请求顺序无关。Floyd–Steinberg 的像素依赖需单独满足，不能把独立平面并行误解为平面内任意重排。
