# 随机过程、参考表与颗粒

> 新实现保留本文明确的状态及距离定义；Gaussian、Gray、浮点颗粒、容量检查的完整规则以 [新实现契约 N06](new-design.md) 为准，替代旧的待决表述。

## F3K-R01 随机状态与离散输出

随机状态 `s` 按 32 位无符号位串解释。所有状态加法、乘法和左移保留低 32 位，右移补零。此规则消除语言中有符号溢出带来的歧义。

状态映射到实数的方法为：令

\[
M(s)=2^{20}s+\lfloor s/2^{12}\rfloor,\qquad U(s)=2M(s)/2^{52}-1.
\]

于是 `U(s)∈[-1,1)`。该定义保留了低位填充规则，不等同于简单的 `s/2³¹-1`。

随机算法产生实数 `u` 后，范围为 `R` 的整数输出为 `Q(uR)`，其中 `Q` 为最近整数、恰好半整数时远离零：正值 `floor(z+0.5)`，非正值 `ceil(z-0.5)`。即使 `R=0`，仍执行随机算法并推进其状态。

## F3K-R02 三种随机算法

**0，legacy。** 对 32 位位串连续施加 xor-shift：先异或左移 13 位的自身，再异或右移 17 位的自身，再异或左移 5 位的自身。更新后的状态经 `U` 映射输出。种子为 0 时该发生器保持 0。

**1，uniform。** 状态递推 `s'=(1664525s+1013904223) mod 2³²`，输出 `U(s')`。参数 `random_param_*` 不参与。

**2，Gaussian。** 连续从 uniform 获取 `x,y`，令 `r²=x²+y²`。若 `r²=0` 或 `r²>1` 则丢弃这对样本并重试。候选值为

\[
z=\sigma y\sqrt{-2\ln(r^2)/r^2}.
\]

仅接受 `-1<z<1`，否则重新获取一对 `x,y`。不保留另一份正态样本供下次使用。这里是拒绝采样得到的截断正态分布，不是将无界正态值 clamp 到端点。`σ=0` 在获得合法圆内样本后返回 0，仍消耗随机数。非有限 `σ` 的处理见待决语义。

算法 0、1 每次调用消耗一次状态更新；Gaussian 消耗可变次数。参考点与颗粒共用一条状态链，两个算法选择器并不表示两条互不相关的 RNG。

## F3K-R03 初始化种子

以亮度宽、高及总帧数混入种子：

\[
s_0=(0x92D68CA2-seed)\ \oplus\ (W\ll16)\ \oplus\ H\ \oplus\ (N\ll16)\ \oplus\ N,
\]

全部按 R01 的 32 位规则计算。改变视频尺寸或总帧数，即使不改变帧内容，也可能改变参考点和颗粒。

## F3K-R04 参考表及随机数消耗顺序

按亮度网格从上到下、每行从左到右生成。每个亮度位置依次发生以下随机事件；次序是确定性兼容契约，不要求采用某种数据结构：

1. 消耗一次范围 `G_Y` 的颗粒随机调用，其值不进入最终像素颗粒。
2. 计算 `r_x=min(range,x,W-1-x)`，`r_y=min(range,y,H-1-y)`。模式 1 用 `R=r_y`，模式 3 用 `R=r_x`，模式 2、4…7 用 `R=min(r_x,r_y)`。
3. 若 `R>0`，消耗一次参考随机调用产生 `r₁`；模式 2 再消耗一次产生 `r₂`。其他模式 `r₂=0`。若 `R=0`，两距离为 0，且不消耗参考随机调用。
4. 当 `x` 可被 `2^s_x` 整除且 `y` 可被 `2^s_y` 整除时，色度网格该位置继承亮度的两个参考距离，然后依次消耗两次范围 `G_C` 的颗粒随机调用，分别对应 Cb、Cr。这两个值同样不作为最终添加颗粒。

色度距离保持亮度单位，读取时才按横纵指数分别缩小。Cb 与 Cr 的参考点相同，不能独立重新抽样。参考表建立完毕后才生成实际颗粒序列。

### 距离离散化与存储（已选定的新设计）

保留 `range=0…255`，默认值仍为 15。每个参考距离精确定义为 `r=abs(Q(uR))`。先在至少 32 位的有符号整数中得到 `q=Q(uR)`，保证 `-R≤q≤R`，再在该类型中取绝对值，最后保存为无符号 8 位距离（`uint8_t`）。因此 `0≤r≤R≤255`。不允许先转为任意 8 位类型再取绝对值，也不允许截断、折回或饱和来替代这个定义。

读取距离时零扩展到足够宽的有符号整数，再按子采样指数缩小并参与坐标加减。坐标加减和行跨度乘法必须使用可表示相应尺寸与地址偏移的有符号类型；不能在无符号 8 位或其他不足宽度的类型中执行负方向运算。R04 的几何距离限制保证参考点位于平面内，不需要通过边缘 clamp 掩盖距离溢出。

旧有符号 8 位窄化导致的距离折回属于缺陷，不保留兼容选项。修改存储符号性不改变随机调用次数、舍入规则、零距离处理或色度共享规则。无符号 8 位与有符号 8 位占用相同空间，两个距离仍只需两个字节；支持上限 255 不要求把整张参考表扩为 16 位字段。具体记录布局可独立优化，但必须保持上述数值契约。

## F3K-R05 实际颗粒序列

令 `A₁₆(w)=16·ceil(w/16)`，定义每段基础长度

\[
L=128\lfloor(W+255)/128\rfloor H.
\]

静态颗粒生成长度 `L`，动态颗粒生成长度 `3L`。先连续生成 Y 序列，再生成同长度 C 序列；每个元素分别是范围 `G_Y` 或 `G_C` 的颗粒随机输出。C 序列仍以亮度尺寸计容量。两个色度平面使用同一 C 序列，不生成独立 Cr 序列。

对平面宽度 `w`，行跨度为 `A₁₆(w)`。帧 `n` 的位置 `(x,y)` 读取序列下标

\[
k=o_n+yA_{16}(w)+x.
\]

行尾填充区域不是可见像素，但其序列元素存在，并影响下一行对应的颗粒索引。`G≤16384`，颗粒元素可用有符号 16 位表示；Deband 后加颗粒必须在更宽的有符号域中计算，不能先饱和到 U16。

## F3K-R06 动态颗粒窗口

静态时 `o_n=0`。动态时，在两条实际颗粒序列全部生成之后，依帧序号 0…N-1 预生成：

\[
o_n=16\left\lfloor\frac{L+Q(U(s')L)}{16}\right\rfloor,
\]

这里固定使用 uniform 发生器，即使颗粒分布选择 Gaussian 或 legacy。每帧一个偏移，同一帧的 Y、Cb、Cr 共用该偏移。实际访问帧 `n` 时使用 `o_(n mod N)`；正常视频请求限定在 `0≤n<N`。

动态颗粒是从有限大表取不同窗口，不是每帧重新生成整张独立噪声。因此窗口可能重叠，偏移也可能重复。“动态”不保证帧间统计独立或每帧图案必然不同。

## F3K-R07 加颗粒

设 Deband 输出为 `D`、读取颗粒为 `g`，传入输出阶段的值为 `Z=D+g`。颗粒在 Deband 阈值判断和梯度计算之后添加，不影响本帧的参考值、角度或平滑决策。即使 Deband 判定保留中心，仍然添加颗粒。
