# 验收与待决语义

> 本文记录历史行为案例及设计演进。下列旧待决项已由 [新实现契约 N01…N09](new-design.md) 作出决定；新实现以 N08 为验收入口，不使用与其冲突的旧平均、舍入、FS、预设或旁路结果。运行验证仍须在实现阶段完成。

本组文档定义行为，并不表示已经存在符合规格的实现。下列案例是独立算子的验收条件；只对整数兼容定义中的完全离散运算要求逐值相等。浮点数学式与快速近似必须分别验收。

Floyd–Steinberg 二像素行例：`Z=[255,255],d=8`，初始误差为 0，full range。第一个输出 0、余数 255，向右送 111；第二个处理值为 366，输出 1、余数 110。该例能区分非负截断余数与最近量化误差。

FS 双 clamp 例：`Z=-10,E=20`，处理值应为 20；若只做最后一次 clamp 会错误得到 10。TV 误差例：`Z=4095,E=0,d=8,keep_tv_range=true`，最终 Y 输出 16，但仍按全范围处理值余数 255 分配误差。

动态颗粒索引例：`W=16,H=16`，基础长度 `L=4096`，行跨度 16。静态平面 `(3,2)` 索引为 35；动态为 `o_n+35`。两个色度平面尺寸相同时，同位置读取同一 C 序列元素。

完整旁路例：8 位输入 Y=0，`output_depth=8`，三个 Y 阈值及 grainy 均为 0，`keep_tv_range=true`，输出仍为 0，而不是 16。

## F3K-A02 组合验收

- 七模式逐个覆盖 8、10、12、16 位输入，输出升位深、同位深、降位深；输入标度始终左移。
- 三种抖动逐个覆盖上下范围、TV 上下端点、负颗粒、正颗粒和边缘像素。
- 用 4:4:4、4:2:2、4:2:0 验证横纵距离分别缩放，Cb/Cr 共用参考位置及颗粒。
- 用尺寸非向量倍数、宽度非 16 倍数、首尾行列验证不可见填充不影响有效像素。
- 用 `range=0,1,127,128,200,255` 验证几何距离及无符号 8 位存储；对零距离允许参考重合。覆盖所有合法整数 `q=-255…255` 的取绝对值、存储和零扩展往返，禁止窄化折回。
- 大范围参考点验收包含首尾行列、平面尺寸小于 range、不同子采样和正负方向坐标；坐标必须在平面内，不能靠无符号回绕或额外 clamp 修补。存储类型变化不得改变 RNG 状态消耗顺序。
- 分别改变 seed、尺寸、总帧数、random 算法、grain 强度和 sample mode，检查共享随机状态链的预期变化。
- 同一帧重复请求、乱序请求与顺序请求结果相同；不同线程数不改变结果。
- FS 使用单平面连续定义作为 oracle，与分块、波前或其他调度逐像素比较；跨块边界不能忽略。
- 精确幂模式 6、7 对照高精度数学表达，单独量化 F32 误差；快速幂变体对照其编码公式，不用精确幂的逐位输出作标准。
- 对 boost 为 0、0.5、1、大于 1，角容差为 0、0.25、0.5、1，以及平坦/垂直/反平行/正交梯度分别验收；`β=1` 与模式 6 使用同一数值路径时结果相同。
- 对非零梯度独立反号、乘非零整数比例，以及共同旋转 90°/镜像，方向判定不变；保持数值在规定范围内。
- 用精确整数叉积/点积和高精度角度参考验证向量快速判定。覆盖阈值两侧、完全相等、接近抵消及最大梯度；误差不确定的位置必须触发重算，不能无条件使用 F32 判断。
- 单独检查 NaN/Inf 角参数、负倍率、越界角参数和阈值乘积溢出的拒绝行为；不把这些输入送进像素循环。

## F3K-A03 历史待决项记录（已由新实现契约收束）

| 问题 | 已明确部分 | 尚需选择或补证 |
|---|---|---|
| 模式 6、7 幂函数 | 精确式与快速编码近似均已定义 | 新设计采用哪种；快速形式的 FMA/中间舍入要求 |
| 模式 7 方向判定（已决定） | D07 无向向量判据、零向量策略及精确端点 | 实现阶段验证快速路径误差界与重算开销；不再选择历史角度差形式 |
| 采样距离（已决定） | 保留 0…255；宽有符号整数取绝对值后存为 `uint8_t`，坐标计算前扩宽 | 实现阶段验证全范围往返、子采样和坐标安全；不保留窄化兼容 |
| 非有限参数 | 模式 7 角参数、倍率及溢出乘积明确拒绝 | 其余参数的 NaN、Inf 策略 |
| Gaussian 参数 | 有限标准差的拒绝采样已定义 | 是否拒绝负标准差；跨数学库逐位一致性是否需要 |
| 浮点舍入 | 最终整数舍入明确 | 内部加法结合顺序、FMA、pow/tan/sqrt/log 精度及容差 |
| 格式校验 | 规格有效域为平面 YUV 整数 8…16 位 | 宿主对奇数尺寸与子采样的合法性检查接口 |
| 非法输出深度/枚举 | 不属于有效域 | 错误应在参数层报告，不能进入未定义移位 |
| 后端一致性 | 算法不依赖后端 | 仍需可运行实现验证，静态数学规格不提供实测证明 |

本规格不把可移植性缺陷、窄化风险或未验证的后端结果自动提升为新实现必须复制的要求。只有明确选定的兼容变体才成为对应配置的验收条件。
