# 时域去噪与修复

## 中值与单向限幅

Clense 使用前、当前、后三个值 p、c、n，输出 `clamp(c,min(p,n),max(p,n))`，等价于三点中值。TemporalMedian 将这个想法扩展到最多 21 帧；场景缩短窗口后，偶数个样本取中间两值平均。

ForwardClense/BackwardClense 以时间上较近的参考为 a、较远的为 b，利用外推值 `2a−b` 与 a 构造区间，再限制 c；类型边界处使用饱和运算。例如 a=100、b=90，则理想范围为 100–110；c=105 保留，c=130 拉回 110。

## TemporalSoften 与 FluxSmooth 的分母

TemporalSoften 对每个时间样本判断 `abs(sample-c) <= threshold`。通过则保留样本，不通过则以 c 替代，最后除以有效窗口长度。

FluxSmooth 先要求 c 为严格时域极值，再只累加通过阈值的邻点，除以实际入选数（包括中心）。FluxSmoothST 额外加入八个空间邻点，但仍先检查时域极值。

例如三个时间值为 `[80,100,95]`，阈值 10：TemporalSoften 的实数平均为 `(100+100+95)/3≈98.33`；FluxSmoothT 因中心 100 大于两侧而进入处理，平均为 `(100+95)/2=97.5`。整数实际结果还遵循各自舍入。两者即使阈值相同也不会必然输出相同结果。

TemporalSoften 的整数实现使用定点倒数归一化，不能用普通浮点除法再四舍五入，作为逐位一致的唯一判据。

## TemporalRepair

主片提供 c，参考片提供时间变化范围。mode 0 用参考三帧同坐标的最小和最大值夹紧 c；没有“不处理”的含义。

mode 1 从参考八邻点估计正、负方向的时域变化；mode 2 从参考 3×3 得到最大的变化幅度并构造对称容许范围；mode 3 比较“到前帧的最大差”和“到后帧的最大差”，取较小者。mode 4 仅使用参考三帧中心的趋势。它们是不同约束，不是线性的强度等级。

修复可以限制之前空间滤镜的修改，但没有恢复被前级滤镜丢弃的信息的保证。没有运动补偿或场景切换参数，切点附近的行为需要由调用方的处理链安排。

## DegrainMedian

从前后帧的对向点、当前帧的空间对向点中选方向。mode 0 选择两端差最小的点对；其他模式同时考虑中心夹紧后的改变量和点对宽度。

设中心夹紧到候选区间后变为 p，改变量 `e=abs(c-p)`，区间宽度为 d。对非负样本，忽略饱和细节的代价如下：

| mode | 代价 |
|---|---|
| 0 | d |
| 1 | e+4d |
| 2 | e+2d |
| 3 | e+d |
| 4 | 2e+d |
| 5 | e |

实际整数运算有饱和，浮点色度路径还受名义负下限约定影响，因此此表用于理解方向选择，不作为替代内核的逐位公式。最后所有模式均用 limit 限制相对当前值的修正幅度。

`interlaced=True` 将空间竖向跨度改为两行，时间仍使用相邻完整帧。`norow=True` 只移除当前帧左右点对，不是禁止所有水平方向信息。

## TTempSmooth

从当前帧向前、向后分别由近到远检查引导样本，同时考察相对于中心及时间连续性的差异。满足条件的样本根据时间距离和差异获得权重；不满足条件会截断该方向的继续累加。

距离 i 的基础时间权重，在 `i < strength` 时为 1，否则为 `1/(i-strength+2)`，再按完整窗口归一化。thresh 与 mdiff 决定是否使用额外的差异权重以及权重衰减区间。较大的 strength 让更多近邻保留较高权重。

设当前值 c、入选加权和 S、已使用权重 W：

```text
fp=True:  S + c*(1-W)
fp=False: S/W
```

S 和 W 都已包括中心项。因此 fp=True 将空余权重保留给中心；False 会让剩下的有效样本重新占满总权重。pfclip 只用于判断与权重，累加的输出颜色来自主片。

边界与场景参数见[时间窗口与场景切换](shared/temporal-boundaries.md)。
