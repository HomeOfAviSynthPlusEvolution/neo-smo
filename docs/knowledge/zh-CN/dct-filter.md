# 块 DCT 与频率加权

[返回知识目录](README.md) · [DCTFilter API](../../api/zh-CN/dct-filter.md)

## 变换与权重

DCTFilter 将每个平面分成从左上角对齐的、不重叠的 8×8 块。每块先做二维 DCT-II，对系数逐项乘权重，再做归一化逆变换。用正交归一化的 DCT 矩阵 C 表示，其数学作用是：

```text
X[v,u] = DCT2(input)[v,u]
W[v,u] = factors[v] * factors[u]
output = IDCT2(X * W)          # * 表示逐项相乘
```

这里 u 是水平方向频率，v 是垂直方向频率，0 表示直流，7 表示该方向最高频率。权重是同一组八个数的外积，无法通过此接口独立设置任意 64 个频率权重或两组不同的横纵系数。

例如 `factors[0]=1`、`factors[1]=0.5` 时，`W[0,1]=W[1,0]=0.5`，但 `W[1,1]=0.25`。直流系数的权重为 `factors[0]²`；只留下直流时，每块输出为其平均值，边缘块的平均值包含补入的样本。

衰减高频会同时削弱噪声和细节。由于块不重叠，也没有相邻块融合，较强衰减可能使块边界更明显；这不是整帧 FFT 卷积，也不是逐像素滑动窗口滤波。

## 补边规则

只有右侧和底部的最后一个块可能不完整。滤镜内部补齐所需样本，输出保留原始尺寸；调用者不需要缩放或裁剪视频。

对长度 N 的一行或一列，向右或向下取样时使用：

```text
index(i) = i                      当 0 <= i < N
index(i) = max(2*N - 1 - i, 0)    当 i >= N
```

例如 `[a,b,c]` 延伸为 `[a,b,c,c,b,a,a,a,...]`。它既不是始终复制 c，也不是无限周期镜像。每个平面独立计算尺寸与块网格；YUV420 的 8×8 色度块覆盖 16×16 个亮度像素的画面范围。

## 精度与归一化

用户系数先以双精度相乘，再转为 64 个 F32 权重，与 Zig 的构造顺序相同。输入像素统一转为 F32 后计算；F16 只用于输入输出存储，不在变换中间插入半精度舍入。

正变换与逆变换已经包含所需的归一化。恒等权重的理想输出为原输入，实际结果可能有浮点舍入误差。调用者不应为补偿变换归一化而额外缩放输入或 factors。

生产允许 FMA。整数写出时裁剪并按正数半整数向上取整，浮点写出不裁剪；F16 最后再转换回半精度。这些差异应与错误的系数索引、重复归一化和错误补边区分开。
