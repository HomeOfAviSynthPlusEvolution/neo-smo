# 采样、阈值与精度

[返回知识目录](../README.md) · [API 通用约定](../../../api/zh-CN/README.md)

## 平面与数值范围

整数名义范围为 `0 … 2^bits−1`。浮点亮度与 RGB 通常为 0–1，浮点 YUV 色度通常为 −0.5–0.5。浮点色度的中性值是 0，不能机械套用整数色度的中点。

这些是参数与算法所用的名义范围，并不表示每个滤镜都会把所有输出强制裁剪到这些区间。某些排序操作直接返回输入样本，某些修复操作则有显式上下限。

同一个半径作用于不同平面时，按各自的像素网格计算。YUV420 的 3×3 色度邻域覆盖的画面范围大于 3×3 亮度邻域。CCD 会另外把参考亮度对齐到色度网格；普通逐平面中值滤镜不会这样做。

## 显式阈值与默认阈值

对于一般带 scalep 的接口，显式指定 `scalep=True` 时：

| 输入格式 | 8 位标度值 t 转换为 |
|---|---|
| 8 位整数 | t |
| 10 位整数 | 4t |
| 16 位整数 | 256t |
| F16/F32 | t/255 |

例如 TemporalSoften 的阈值 4，在 10 位输入上写 `threshold=[4], scalep=True` 得到 16；省略 threshold 也使用这一缩放后的默认值。写 `threshold=[4]` 则是原生 4。

DegrainMedian 的显式 limit 是例外：整数按 `(2^bits−1)/255` 缩放，浮点亮度/RGB 按 `1/255`，浮点色度按 `0.5/255`。省略 limit 则始终保留原生 4。因此浮点输入下，省略与显式 `[4], scalep=True` 的作用可能明显不同。

TTempSmooth 的 thresh/mdiff、Cnr4 的 sense/str 及 CCD 的 threshold 各有自己的归一化规则，没有 scalep 参数。不要给所有接口套同一个换算函数。

## F16 与 F32

F16 是输入输出的半精度浮点存储格式；并非将 F32 数组换一种名字。对于采用半精度算术的内核，支持原生半精度的编译目标可直接使用 F16 运算，不支持时使用 F32 计算并在输出时写回 F16。部分步骤仍会按算法需求使用更宽类型，不能把整个滤镜理解为“每条指令都用 16 位”。

DCTFilter 固定使用 F32 执行变换，包括 F16 输入；只在读写时转换半精度，不随原生 F16 指令支持情况改变计算精度。系数不使用位深阈值缩放，浮点输出也不裁剪到名义范围。见[块 DCT 与频率加权](../dct-filter.md)。

这两种半精度算术路径的中间舍入不同。以多个小数相加为例，逐次半精度舍入与先用 F32 累加、最后转为 F16，可能得到相邻但不相同的结果。F16 输入也不会必然比 F32 更快，实际收益取决于 CPU、编译目标与算法。

生产实现允许 FMA。融合乘加只舍入一次，与分开的乘法和加法可能相差少量末位。对照测试应区分纯数值误差与索引、采样、边界或模式错误；不要求为了逐位匹配而在生产路径额外插入半精度往返转换。

## SIMD 与测试解释

Highway 按构建中可用的目标与运行平台选择 SIMD 路径，公开接口不提供 SIMD OFF 或 opt 参数。不同目标的运算顺序可能不同，浮点输出不承诺逐位一致。

检查输出时，应同时记录格式、参数、帧号、平面和最大差异。阈值附近的一个舍入差可能改变某个样本是否入选，因此只给一个“测试通过数”不能描述实际误差；反过来，也不应把任何差异都自动归因于 FMA。
