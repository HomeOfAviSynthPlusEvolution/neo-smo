# RemoveGrain

[返回 API 目录](README.md)

```python
core.neo_smo.RemoveGrain(clip, mode)
```

支持通用格式。`mode` 必填，逐平面取值 0–24，最后一项重复。没有 `planes` 参数，使用 mode 0 保留对应平面。其余模式使用镜像边界的 3×3 邻域。

| mode | 行为概要 |
|---|---|
| 0 | 复制 |
| 1 | 限制到周围八点的最小值与最大值之间 |
| 2–4 | 将八邻点排序，逐渐收窄上下限；4 的界限为中间两个邻点 |
| 5–9 | 在四组对向邻点中选择代价最小的方向并限幅；代价定义见知识页 |
| 10 | 取与中心最接近的邻点 |
| 11、12 | 相同的 3×3 加权平均：中心权重 4，十字邻点 2，角点 1，总权重 16 |
| 13、14 | 选择上下／对角方向中两端差最小的一对，取其平均；13 处理偶数行，14 处理奇数行 |
| 15、16 | 对上下两行加权平均，再按上述最佳方向限幅；15 处理偶数行，16 处理奇数行 |
| 17 | 用四组对向邻点范围的内侧端点构造上下限 |
| 18 | 按“中心到一对端点的最大差”选择方向，再限幅 |
| 19 | 八邻点平均，不含中心 |
| 20 | 九点平均，包含中心 |
| 21、22 | 将中心限制到四组对向均值的范围；整数舍入规则不同，浮点两者相同 |
| 23、24 | 按方向区间宽度限制向上、向下的修正；24 的修正还随越界距离减弱 |

行号从 0 开始。13–16 未选中的行直接复制，不读取场序属性。模式号不是统一的强度刻度，不能把 24 理解为“比 1 强 24 倍”。

```python
out = core.neo_smo.RemoveGrain(src, mode=[2, 0, 0])
```

公式与方向选择见[空间排序与限幅](../../knowledge/zh-CN/spatial.md)。
